# Reading List

Background reading, cross-referenced from [[DanKG]]'s architecture section.

## Graph drawing

- Sugiyama, Tagawa, Toda -- "Methods for Visual Understanding of
  Hierarchical System Structures" (1981): the source of the four-phase
  layout described in [DanKG's architecture](../projects/dankg.md#architecture).
- Brandes & Kopf -- fast and simple horizontal coordinate assignment.

## Markdown & parsing

- The CommonMark spec -- the conformance suite DanKG scores itself
  against. Nothing else in this corpus links here, so this heading shows
  up with no incoming edges.
